# AI Usage and Development Reflection

## Mini AI Business Intelligence Assistant

### 1. AI Tools Used

- **Google Gemini API:** Used within the application to classify natural-language business questions into supported analytical intents.
- **Antigravity:** Used for implementation assistance, code review, and debugging.
- **ChatGPT:** Used for technical guidance, troubleshooting, reviewing backend logic, and preparing documentation.
- **Claude:** Used for coding assistance, reviewing implementation approaches, and improving code quality.

### 2. How AI Was Used During Development

AI tools helped me understand the requirements, structure the application, and improve my implementation. The application uses the Google Gemini API to identify questions about total revenue, the highest-revenue product, monthly trends, regional sales, and comparisons between months.

The identified intent is mapped to predefined SQL queries executed against a SQLite database. Revenue calculations are performed using stored sales data rather than being generated by the AI model. AI coding assistants also helped me review Python code, identify potential issues, and improve error handling and automated tests.

### 3. Problems Encountered

One challenge was handling Gemini API failures and classifying ambiguous questions correctly. I also encountered Python environment and package issues, along with API connectivity problems.

Data quality required attention as well, including duplicate transactions, missing values, invalid dates, and transactions that should not contribute to revenue. Ensuring consistent communication between the backend and frontend was another important part of development.

### 4. How the Problems Were Debugged

I investigated issues by checking Python error messages, API responses, and application logs. I tested API endpoints using FastAPI's Swagger interface and verified database query results against the expected calculations.

I also used automated tests with temporary databases and sample data to check calculations, excluded transactions, invalid inputs, and API error handling. AI tools helped me understand possible causes and fixes, which I then checked against the application's behavior.

### 5. What I Would Improve With Another Day of Work

With one additional day, I would improve intent classification for ambiguous questions, add more tests for edge cases, and strengthen data validation. I would also ensure that the dashboard's dataset timeframe is derived dynamically and improve the presentation of monthly trends and query results.

Finally, I would test the complete application from CSV loading to frontend display and verify the setup instructions in a clean environment.

### Conclusion

This project helped me understand how to combine AI with a database-driven application. I learned that AI can help interpret questions, but business calculations should rely on validated data and predefined SQL queries. It also taught me the importance of testing AI-assisted code and verifying that the application produces reliable results.
